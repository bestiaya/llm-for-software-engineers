# K01-09 参数怎样学

有了损失这把尺子，本章回答每个参数该往哪边改、改多少。先拨动一个输出偏置看损失怎样变，照着变化率做一次更新；再沿一条短链，把隔着两层的参数的变化率一段一段算出来，并用拨动法核对程序算出的全部梯度。

这是阶段二里最重的一章，建议分两次学：第一次到“照着变化率改一次”为止。

- [阅读正文](lesson.md)。
- 网络的计算在[共享代码](../shared/network.py)里：前向、两种梯度算法、一次更新。

先按[课程导读的实验准备](../ABOUT.md#lab-setup)进入课程仓库根目录。本章的实验全部离线，只做一次更新，不训练。

```bash
python3 v2/09-update/lab.py
python3 v2/09-update/lab.py --chain
python3 v2/09-update/lab.py --check
```

第一条只动三个输出偏置：拨动，看损失，更新一次，从头复算。第二条沿一条短链手算第一层一个权重的变化率，再用拨动法核对。第三条在训练的起点上，用拨动法抽查程序算出的全部 27 个梯度。

先预测再核对的那道题：

```bash
python3 v2/09-update/lab.py --chain --label 0
```

前两条命令各用一组为手算挑的参数，第三条用训练的起点。三组都不是训练的结果，输出的第一行会标明。加 `--json` 看全部字段。
