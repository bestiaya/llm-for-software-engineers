# 第07章教学蓝图

面向会编程、尚未系统学过机器学习的软件工程师。读完能用三行数据说明线性模型的表达限制及其前提，说出非线性激活和隐藏层各起什么作用，并亲手跟踪一行输入走过隐藏层的计算。

## 阅读顺序

1. 接上一章的问题：换一组参数能不能全对。用三行训练数据推理：中间一行的分数是两端的平均，两端选对则中间必错。先用数值表验证“取平均”，再给三步推理；实验里的随机尝试只作旁证。
2. 给结论加上范围：前提是输入为原始次数。换成“是否达到 2 次”的表示后，线性模型够用。由此分出两条出路：人来换输入，或让模型自己算出新的表示。
3. 排除“多叠一层乘加”：合起来仍是一次乘加。用去掉 ReLU 的实验让读者看到 16 行的分数完全相同。完整推导放选读。
4. 引入 ReLU：取 0 和这个数当中较大的那个。用 −1、0、1 说明它不守“取平均”；用两个单元对 a 的四种取值列表，得到“是否达到 2 次”。
5. 带隐藏层的网络：结构、27 个参数、手设的四个隐藏单元和输出层的构造。跟踪 a=0、b=2 的四步，读者自己跟踪 a=3、b=1，再看 16 行全对。
6. 中间表示：输出层仍只做乘加，够用是因为面对的是隐藏值。写明手设参数只说明结构够用，不说明训练能找到。

## 核对依据

三行数据的分数、两端平均与中间的关系、随机尝试的结果、去掉 ReLU 后的分数、两条路径的四步结果和 16 行的结果，都来自 `lab.py` 的输出，由测试固定。“换成是否达到 2 次以后线性模型 16 行全对”和选读里合并后的权重与偏置，由测试直接计算核对。

必须落实的限定：线性模型做不到的结论限定在当前的输入表示；手设参数的成功不当成训练的成功。

选读只有一处：两层乘加合并成一层的推导。
