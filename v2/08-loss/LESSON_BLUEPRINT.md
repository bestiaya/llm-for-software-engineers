# 第08章教学蓝图

面向会编程、尚未系统学过机器学习的软件工程师。读完能把三个分数算成三个概率，用正确类别的概率算一行的损失，对一组数据取平均，并说明模型给的概率不自动等于现实里的正确率，以及损失和选对的行数何时不一致。

## 阅读顺序

1. 从上一章的问题接上：选对的行数分不出同样选对的两个结果，对参数的小改动也没有反应。新尺子要补上这两条。
2. 分数变概率：先给指数的数值表和三条性质，用 0、0.693、1.099 这组好算的分数走三步，再算上一章那一行真实的分数。之后才给名字 softmax 和代码。让读者自己试两个性质：只有差距起作用，差距越大份额越悬殊。
3. 这个概率是什么：模型按当前参数分配的份额。用“输出层乘 3、选择完全相同、概率却不同”说明它不自动等于正确比例，引出校准这个词，并指向大语言模型每一步的输出。
4. 概率变损失：只看正确类别的概率，给 −ln 的数值表，再给名字。用它回答开头的比较。给出三类平分时 1.099 这个参照。
5. 取平均：先算三行的小题，再看 16 行。说明第 04 章的验证损失就是这个数。
6. 两把尺子说法不一样的例子，数是人工构造的并标明。说明各自的用处。
7. 公式放最后，可以跳过。

## 核对依据

正文里的指数表、对数表、两组分数的三步结果、16 行的概率与平均损失、输出层乘 3 以后的结果、两个人工模型的行数与损失，都来自 `lab.py` 的输出，由测试固定。正文里的 `softmax` 和 `mean_loss` 由测试执行并与共享代码比较。

沿用课程设计里已核对的两个算例：分数 0、ln 2、ln 3 得到 1/6、2/6、3/6；概率 0.25、0.5、0.75 的损失平均约 0.789。

必须落实的限定：模型给正确类别分配的概率，不自动等于现实里的正确率。
