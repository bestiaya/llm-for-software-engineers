# K01-14 走通完整的预测（核心部分草稿）

> **这是草稿。** 它是为验证“这一章做不做得出来”写的核心部分，还不是完整的一章：没有开篇的衔接、图、小测和选读，也没有接入课程目录。前面的第 11 到 13 章还没有写，这里假定读者已经会四件事：把一句话按词表变成编号；按编号取出词向量；用注意力按权重读前文，并且知道因果遮罩；把分数变成概率。文中的数字都来自本目录的实验，可以运行核对。

到上一章为止，你会算注意力：最后一个位置给前面每个位置打分，归一成权重，再按权重把前文读成一个向量。可是从“读到一个向量”到“七个候选各有多大概率”，中间还缺几段。这一章把它们补齐，沿一条完整的路径走一遍。

用的还是那两句话：

    请求 成功 后 返回 EOS
    请求 失败 后 重试 EOS

这一章用的参数是**训练出来的**，不再是前两章为了好算而手设的那些。怎样训练出来的，放到第 16 章。所以下面的数不整齐，也看不出哪个数代表什么意思。这是训练得到的参数的常态，能核对的是每一步的算法和最后的行为。

## 一条路径，六步

先看整条路径，再逐段讲新加的部分。前文是“请求 成功 后”，要预测下一个词。

```bash
python3 v2/14-forward/lab.py
```

| 步 | 做什么 | 结果的形状 | 哪一章讲的 |
| --- | --- | --- | --- |
| ① 编号 | 三个词按词表换成编号 0、1、3 | 3 个编号 | 第 11 章 |
| ② 查表，加位置 | 每个编号取一行词向量，再加上所在位置的向量 | 3 个位置，各 2 个数 | 第 12 章，位置是本章新加的 |
| ③ 注意力 | 最后一个位置按权重读前面三个位置 | 3 个权重，读到 2 个数 | 第 13 章 |
| ④ 前馈 | 把读到的向量再加工一次 | 先变成 4 个数，再变回 2 个数 | 本章新加 |
| ⑤ 输出 | 给词表里的每个候选打一个分 | 7 个分数 | 本章新加 |
| ⑥ 概率 | 七个分数变成七个概率 | 7 个概率 | 第 08 章 |

这次的结果：“返回”的概率是 1.000，其余六个加起来不到千分之一。

这张表给的是“最后一个位置”的预测。别的位置也各有一份同样的计算，各自预测自己后面的那个词，上一章已经见过。

## 顺序是从哪里进来的

注意力按内容读前文：打分只看两个位置上的向量，不看它们隔多远、谁在前。如果向量里只有“这是哪个词”，那么把前面的词换个顺序，最后一个位置读到的东西完全一样。

所以要把位置也放进向量。做法很直接：除了词向量表，再准备一张**位置向量表**，第 0 个位置一行，第 1 个位置一行，一共 4 行，每行 2 个数。查完词向量，把所在位置的那一行加上去：

    “成功”在第 1 个位置：词向量 [1.416, 0.538] + 位置向量 [2.364, 0.703] = [3.780, 1.242]

第二个数按显示的值相加是 1.241，程序显示 1.242。显示的数都四舍五入过，末位差 1 是正常的。

位置向量和词向量一样，是可以训练的参数。

可以直接检查“顺序靠位置向量进来”这句话。把“请求 成功 后”的前两个词对调成“成功 请求 后”，比较最后一个位置的预测：

```bash
python3 v2/14-forward/lab.py --order-check
```

- 有位置向量时，两段前文的预测不一样，概率最多相差 0.010。
- 把位置向量全换成 0，两段前文的预测完全一样，一点差别都没有。

第二条才是要看的。去掉位置向量以后，模型本身的预测也乱了，这不奇怪，它是带着位置向量训练的。这里只比较两段前文之间有没有差别。

要说明一点：这两句话的训练数据里，没有哪两句只靠顺序来区分。所以这个检查说明的是**机制**，顺序信息只能从位置向量进来；它不说明这个小任务离了位置向量就做不成。

## 读完以后，再加工一次

注意力做的是读取：把前文几个位置的向量按权重合成一个。这次读到的是 [0.515, 0.646]。

接下来的**前馈变换**，就是第 07 章那种两层的计算，接在每个位置的后面：先乘一组权重、加偏置，得到 4 个隐藏值；过 ReLU，小于 0 的变成 0；再乘一组权重、加偏置，变回 2 个数。

第一步可以跟着算。先把这组权重和偏置打印出来：

```bash
python3 v2/14-forward/lab.py --show W1
python3 v2/14-forward/lab.py --show b1
```

| 隐藏单元 | 算式 | 过 ReLU 之前 | 过 ReLU 之后 |
| --- | --- | ---: | ---: |
| 第 0 个 | 0.515×0.190 + 0.646×(−0.527) + 2.871 | 2.628 | 2.629 |
| 第 1 个 | 0.515×0.478 + 0.646×(−0.207) − 0.206 | −0.094 | 0 |
| 第 2 个 | 0.515×1.493 + 0.646×2.488 + 1.769 | 4.145 | 4.145 |
| 第 3 个 | 0.515×(−0.317) + 0.646×0.129 − 0.250 | −0.330 | 0 |

第 0 个按显示的数算出 2.628，程序给的是 2.629，还是四舍五入造成的。四个隐藏值是 [2.629, 0, 4.145, 0]：两个单元被 ReLU 关掉了。再乘第二组权重、加偏置，得到 [10.218, −0.311]。

它为什么要有：读取只是把已有的向量按比例混在一起，前馈变换才对混出来的结果做一次带 ReLU 的计算。第 07 章已经见过，加了这一层以后能表达的关系比单纯乘加要多。

注意输出又回到了 2 个数，和这一层输入的向量一样长。这一点后面要用。

## 给词表里的每个候选打分

最后一段和第 05 章的输出层是同一种计算，只是候选从 3 个类别换成了词表里的 7 个词：用一个 2 行 7 列的权重表，加上 7 个偏置，把 [10.218, −0.311] 变成 7 个分数。

    “返回”的分数 = 10.218×1.920 + (−0.311)×(−0.058) + 1.874 = 21.51
    “EOS”的分数 = 10.218×1.159 + (−0.311)×1.736 + 2.058 = 13.36

七个分数是 −0.40、−14.05、−14.06、−3.56、21.51、12.71、13.36。“返回”比第二名高出 8 分多。softmax 之后，8 分的差距变成几千倍的概率差距，所以“返回”的概率显示为 1.000。

到这里，一次预测走完了：**模型的输出是词表上的一组概率，每个候选一个。** 它还不是一个词，更不是一段话。怎样从这组概率里选出一个词、再接着往下算，是下一章的事。

## 这个模型有多少参数

把路径上用到的每一块数一遍：

```bash
python3 v2/14-forward/lab.py --count
```

| 哪一块 | 形状 | 个数 |
| --- | --- | ---: |
| 词向量表 | 7 行 2 列 | 14 |
| 位置向量表 | 4 行 2 列 | 8 |
| 注意力的查询、键、值三个映射 | 各 2 行 2 列 | 12 |
| 前馈的第一组权重和偏置 | 2 行 4 列，加 4 个 | 12 |
| 前馈的第二组权重和偏置 | 4 行 2 列，加 2 个 | 10 |
| 输出的权重和偏置 | 2 行 7 列，加 7 个 | 21 |
| 合计 | | 77 |

77 个参数，每个按 4 字节的单精度数保存，权重一共占 308 字节。

这只是**权重的存储量**。运行的时候，每个位置的向量、打分、权重、隐藏值都要另外占地方，前文越长占得越多。所以“模型文件多大”和“运行时要多少内存”是两个数，不能互相代替。

## 和真正的大模型差在哪里

这条路径上的计算关系是真的：查表、加位置、带遮罩的注意力、前馈变换、到词表的输出。但它是刻意简化过的，差别要说清楚：

- **只有一层。** 真正的模型把“注意力加前馈”这一段重复叠很多层，上一层每个位置输出的向量，作为下一层的输入。前面说前馈的输出和输入一样长，就是为了能这样接下去。
- **只有一个注意力头。** 真正的模型在同一层里并排放多组注意力，各读各的，再把结果合起来，叫多头。
- **没有残差连接。** 真正的模型在注意力和前馈各自的旁边留一条直通的路，把这一段的输入直接加到输出上。层数多了以后，有它训练才容易进行。
- **没有归一化。** 真正的模型在这些段落之间把向量的大小调整到稳定的范围。
- **尺寸差得很远。** 这里的向量是 2 个数，词表 7 个词，最多读 4 个位置。真正的模型里，向量有几百到上万个数，词表有几万到几十万个 token，能读的位置从几千到上百万。

后面三项这一章只说它们的位置和作用，推导和实现放在选读。

还有一点：不要把这条路径读成“注意力叠起来就得到了文本”。每一层里注意力之后都有前馈，最后还要有到词表的输出，得到的也只是下一个词的概率。

## 换一个条件，先预测再核对

**第一题。** 把前文换成“请求 失败 后”。先自己判断：六步里哪几步的数会变？第 ③ 步的三个权重会差很多吗？最后概率最大的是哪个词？

```bash
python3 v2/14-forward/lab.py --prefix "请求 失败 后"
```

参考答案：第 ① 步的第二个编号从 1 变成 2，所以第 ② 步第二个位置的向量变了，后面每一步都跟着变。第 ③ 步的权重几乎没有变，是 0.356、0.305、0.339，原来是 0.356、0.306、0.339；变的是被读的内容，读到的向量从 [0.515, 0.646] 变成 [0.181, −0.170]。最后“重试”的概率是 0.999。

**第二题。** 把向量从 2 个数加到 4 个数，前馈的隐藏单元从 4 个加到 8 个，词表和最多读的位置数不变。按上面那张表逐块重算，一共多少个参数？占多少字节？

```bash
python3 v2/14-forward/lab.py --count --dimension 4 --hidden 8
```

参考答案：28 + 16 + 48 + 40 + 36 + 35 = 203 个，812 字节。两个尺寸各加一倍，参数不止多一倍：注意力的三个映射和前馈的两组权重，个数都是两个尺寸相乘，各变成了原来的四倍。
