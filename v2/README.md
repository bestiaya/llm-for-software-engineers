# K01 给软件工程师的大语言模型课

这是课程目录：各章从哪里读，实验怎样运行。

课程从一次成都天气查询开始。先看一次请求怎样完成，并判断它做得对不对；再打开模型，理解参数怎样计算和学习；接着看这些计算怎样生成文本；最后分析限制，并用评测判断是否更换模型。全课暂定 22 章，分五个阶段，按顺序学完。现在写成了前 10 章，后面的章逐章更新。

## 从哪里进

先读[课程导读](ABOUT.md)，再按下面的章节表从 K01-01 往后读。每章结尾有通向下一章的链接。

课程导读说明目标读者、初衷、课程地图与取舍，也写明实验怎样准备。

课程的正文只有 Markdown 一种形式：各章目录下的 `lesson.md`。在 GitHub 上可以直接读；下载到本地以后，用编辑器或任何 Markdown 预览工具读。每章目录里还有两样读者用得上的东西：`lab.py` 是实验脚本，`README.md` 列出这一章的全部命令。

## 阶段一：先完成一次应用判断

按 K01-01 → K01-02 → K01-03 阅读。读完这三章，你走通了一次真实调用，写清了什么算对，并做出了第一份评测。这是全课的第一个入门里程碑。

| 章 | 本章完成什么 | 正文 |
| --- | --- | --- |
| K01-01 一次请求怎样走完整个系统 | 回放 GPT 提取城市和天数的真实调用，核对应用怎样查询并展示逐日预报 | [阅读](01-request/lesson.md) |
| K01-02 把任务说清楚 | 把约定扩成查询、请求澄清、不支持三种结果，为十条输入写期望行为，分清哪些归模型、哪些归程序 | [阅读](02-contract/lesson.md) |
| K01-03 第一份评测 | 用固定的标准逐题评价两版应用，检验评分程序本身，说明这十条题能支持什么结论 | [阅读](03-eval/lesson.md) |

每章都有图、可运行的实验和四道带答案的小测。建议先写自己的答案，再展开核对。

## 运行阶段一的实验

先按[课程导读的实验准备](ABOUT.md#lab-setup)进入课程仓库根目录。三章的实验只用 Python 标准库，默认读取随课保存的记录，不联网，不调用模型。

```bash
python3 v2/01-request/lab.py
python3 v2/02-contract/lab.py
python3 v2/03-eval/lab.py
python3 v2/03-eval/lab.py --compare
```

各条命令都可以加 `--json` 对照字段。第 01 章回放一次真实的 GPT 调用和一次 Open-Meteo 天气服务响应；第 02 章演示约定怎样把模型交回的文本变成应用的行为；第 03 章回放十条输入在两版应用下的真实模型回答，并逐题评分。各章目录里的 `README.md` 列出了更多命令和记录的来源。

## 阶段二：计算与学习

按 K01-04 → K01-10 阅读。这七章换成一个小到每一步都能算出来的数值任务：两个数进去，三个类别里选一个，全部数据只有 16 行。读完你能跟着一个小网络从输入算到损失，做一次参数更新，并读懂一份训练记录。这个小任务上的结果只用来看清机制，不说明大语言模型的能力。

| 章 | 本章完成什么 | 正文 |
| --- | --- | --- |
| K01-04 从例子里学 | 看一遍完整的学习过程，认识输入、标签和标注规则，分清 16 行数据的三种用途，看一个答案进了输入的反例 | [阅读](04-task/lesson.md) |
| K01-05 模型就是参数加一套算法 | 读出九个参数，手算一行输入的三个分数并得到类别，分清改输入、改参数和改外部数据 | [阅读](05-models/lesson.md) |
| K01-06 一次算一批 | 用向量、矩阵和形状一次算一批输入，分清每个轴的含义，识别形状正确而含义错误的计算 | [阅读](06-math/lesson.md) |
| K01-07 一层不够 | 用三行数据说明只做乘加的模型的限制，跟着一行输入走过隐藏层和 ReLU | [阅读](07-hidden/lesson.md) |
| K01-08 从分数到概率和损失 | 把三个分数变成三个概率，用正确类别的概率算损失；模型给的概率不自动等于现实里的正确率 | [阅读](08-loss/lesson.md) |
| K01-09 参数怎样学 | 拨动一个参数看损失怎样变，做一次实际的更新，沿一条短链把变化率传回去 | [阅读](09-update/lesson.md) |
| K01-10 学得怎样 | 实际训练一遍，比较训练、验证、留出三组数据和两个基线，认识欠拟合与过拟合；含阶段检查 | [阅读](10-training/lesson.md) |

第 07 到 10 章偏重，其中第 09 章最重，正文中间设了停顿的地方和小测，建议分两次学。数学只用到乘加、取较大者、指数和自然对数，用到的地方都先给数值表。

## 运行阶段二的实验

七章的实验同样只用 Python 标准库，全部离线。第 04 到 09 章不训练；第 10 章会真的训练一遍，不到一秒。

```bash
python3 v2/04-task/lab.py --preview
python3 v2/05-models/lab.py
python3 v2/06-math/lab.py
python3 v2/07-hidden/lab.py
python3 v2/08-loss/lab.py --row 0 2
python3 v2/09-update/lab.py
python3 v2/10-training/lab.py
```

各章目录里的 `README.md` 列出了全部命令。[共享数据说明](data/README.md)列出 16 行数据、九个手设参数和训练记录的来源。
