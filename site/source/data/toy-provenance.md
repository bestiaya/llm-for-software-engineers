# 原创有限语法语料

语料由 `llm_course/data.py::toy_groups` 确定性生成，无外部来源、无真实业务日志。每组含 2–7 个片段，每个片段为 `服务正常。` 或 `服务超时，重试。`。枚举所有二元片段序列，共 252 个唯一完整文本。该原创文字及生成代码按本仓库许可证提供。

训练时使用局部 `random.Random(seed)` 打乱完整文本组，按前 201 / 中 25 / 后 26 组分 train / validation / test，之后才拟合训练字符词表和构建窗口。每组尾部添加专用 EOS token，不将字符串 `<EOS>` 当成 5 个字符。UNK=0、EOS=1；无 PAD。

每组内部字符按 context 长度为跨度形成移位输入/目标，短尾保留，每个原始组从第二字符到 EOS 每个目标恰好一次。训练窗口按长度分桶避免 padding；评估所有窗口，损失按目标数加权。报告的语料 SHA-256 对应按生成顺序以 `\n` 拼接全部组的 UTF-8 字节。

完整组不相交不代表统计独立：所有组共享相同有限语法，长组含有短组相同片段。低损失只说明拟合这种资料的能力；不能推断自然语言理解、真实业务判断或通用生成能力。语法直接允许重复，因此 toy 生成重复不是违反训练语法。
