# 16｜预训练、SFT与偏好：究竟改了什么

本章解释为什么“会续写文本”与“按要求回答”之间还有距离，并用一个答案遮罩与一个局部低秩矩阵实验，把后训练从名词落到计算。先读[下一token训练](13-next-token.md)和[自然文本实验](15-real-text.md)。本章不训练通用聊天助手。

## 1. 规模能改变容量，不能替代数据目标

这节先区分架构、模型类别与系统，避免把Transformer等同于所有AI。

Transformer是一类神经网络架构；语言模型可以采用它预测文本；LLM是大语言模型类别；聊天产品还需要交互、工具、权限与评估。机器学习也包含计数、线性模型、树等路线，并不全是Transformer。本课小decoder演示一条路径，不是AI的全貌。

规模至少有参数、数据、计算预算三条轴。独立小例：一个线性层从4维到6维，无偏置时有 `4×6=24` 个参数；宽度翻倍到8维与12维，有 `8×12=96` 个，是4倍，不是2倍。若增加偏置还要加6或12个。完整模型还包括嵌入、注意力、FFN与归一化，不能只用一张线性层矩阵推总参数。

多给参数扩大可调空间，多给数据增加观察，多给计算允许做更多更新。哪一项成为瓶颈必须测，不能把小模型300步失败全部归于“参数不够”，也不能把更多同质数据当成新的知识覆盖。

## 2. 三种训练阶段的依据

这节用同一个“发布失败怎么办”例子区分数据与目标。

| 阶段 | 提供什么数据 | 训练依据 | 尚未保证什么 |
|---|---|---|---|
| 预训练 | 大量文本片段 | 预测文本里的下一token | 不保证遵循指令或事实正确 |
| SFT监督微调 | 提示与示范回答 | 使示范回答在提示条件下更可能 | 不保证示范覆盖所有问题 |
| 偏好学习 | 同一提示下回答的偏好比较等反馈 | 调整对更受偏好回答的倾向 | 偏好不等于事实真相 |

预训练目标可以由文本自身构造，常称自监督；SFT的答案可以由人或明确流程提供。这里的“监督”指训练依据，不是每一步都有人盯着运行。后训练是预训练之后调整行为的一组方法，并不是任何模型都必须按唯一固定顺序走完的流水线。

同一句“测试失败时回滚”，出现在普通文本里，是续写材料；作为“问：测试失败如何处理？答：测试失败时回滚”的答案，是示范行为。字符串相似，组织方式、损失位置和任务条件仍可不同。

## 3. SFT只算答案，提示仍然可见

这节手算移位后的答案遮罩，区分注意力访问权限与损失计分位置。

用符号序列 `[Q,分隔,A,B,EOS]`。Q和分隔属于提示，A/B/EOS属于回答。训练输入、目标与计分规则是：

| 输入位置 | 当前输入 | 移位目标 | 计损失吗 | 理由 |
|---|---|---|---|---|
| 0 | Q | 分隔 | 否 | 目标仍属于提示 |
| 1 | 分隔 | A | 是 | 目标是首个答案token |
| 2 | A | B | 是 | 目标属于答案 |
| 3 | B | EOS | 是 | 学会回答结束 |

常见错位是按“当前输入是否属于答案”来遮罩：这样会漏掉预测A的那一行。规则应看**移位目标的来源**。提示不计损失不代表删除提示：答案计算依然要读提示，而且梯度仍可通过答案的计算路径影响参与表示提示的参数。

若四行正确目标的概率依次为 `0.1、0.5、0.25、0.8`，只取后三项，平均损失是 `(0.693147+1.386294+0.223144)/3≈0.767528`；第一项 `-ln0.1≈2.302585` 不进入分子，也不进入分母。若没有任何答案目标，应报错，不能除以0，也不能悄悄当作损失0。

```bash
python3 -m llm_course.experiments
```

其中SFT小实验使用序列 `[2,3,4,5,1]`，答案从原序列下标3开始，因此只计目标5与EOS(ID1)，遮罩为 `[false,false,true,true]`。它用6候选的全零logits，两个有效目标的损失都为 `ln6≈1.791759`；一次实际运行得到1.79175949097，与浮点精度下的手算相符。这验证的是移位和遮罩算术，没有执行完整模型指令微调。

## 4. 偏好不是一条标准答案

这节通过两条回答解释偏好目标，知道它和SFT的差别。

同一提示“发布测试失败怎么办”，A回答“先检查失败原因，必要时回滚”，B回答“忽略失败继续发布”。若收集到10次比较，有8次选A、2次选B，那么80%是**这批比较的选择频率**，不是“A有80%概率事实正确”。评审人、任务条件和题目分布都会影响偏好。

SFT给出要模仿的序列；偏好学习利用相对选择。RLHF的一类流程先用偏好训练奖励模型，再用强化学习调整语言模型；DPO直接从成对偏好构造优化目标，是另一条方法。不是所有后训练都必须训练奖励模型，也不是有偏好数据就能自动消除幻觉。

难点看不懂可跳过，记住：答案“受欢迎”、引用“有证据”、动作“被授权”是三个问题。优化前者不能替代后两者的检验。完整偏好算法需要新的训练代码与评估，本课不把这张小表称作已完成对齐。

## 5. LoRA选修：只更新一个低秩修正

这节用一个可手算矩阵说明减少可训练参数的方法，不把它等同于某个训练目标。

先冻结原来的4输入、4输出矩阵W，共16个参数；新增A形状1×4、B形状4×1，总计8个可训练参数。取 `A=[1,0,0,0]`，`B=[[0.1],[0.2],[0],[0]]`，缩放取1，输入列向量为 `[2,1,0,-1]`：

```text
A x = 1×2+0×1+0×0+0×(-1) = 2
B (A x) = [0.2,0.4,0,0]
新输出 = W x + [0.2,0.4,0,0]
```

公式是 `新输出 = W x + (α/r) B A x`。`r`读“秩参数”，是中间宽度，这里为1；`α`读“阿尔法”，是缩放系数，这里为1；W冻结，A和B训练。矩阵乘法的顺序由右向左，先Ax再乘B。此处改用列向量明确配合形状，不能直接拿前章行向量的数组照抄。

上面的实验命令还会训练一个独立LoRALinear层，检查基础权重未变、A/B变化；随课一次实跑中，这三项检查均符合预期。它的损失用局部数值目标，不是语言SFT；LoRA是参数更新方式，SFT是数据与目标组织方式，两者可以组合但不是同义词。小矩阵下省一半参数不表示整个大模型总显存必定省一半：优化器状态、激活、缓存仍占空间。

## 6. 换数小测

这节检查能否把训练依据与实现机制分开。

1. `[P1,P2,R1,EOS]`，答案从R1开始，移位后的目标和loss mask是什么？
2. 原线性矩阵8输出、6输入，LoRA秩2。原参数与新增参数分别多少？忽略偏置。
