# 05｜梯度：怎样知道一个参数应该往哪边改

**梯度测量参数小幅增加时，损失会怎样变化；梯度下降沿相反方向走一小步，再重新计算。它提供局部方向，不保证每步都改善所有样本。** 本章会亲手完成一次更新，最后得到可核对的新概率和损失。

前置：[第03章的交叉熵](03-counting.md)、[第04章的参数分数](04-parameters.md)。本章先直接更新一个输入行的三个分数，相当于训练一张分数表的一行；它们不是任意深层模型中可直接独立改动的最终输出。

## 1. 先做一个不用微积分的实验

这节用“稍微拧一下参数”观察损失，带走梯度正负号的实际意义。

词表A/B/C，真实下一项为B，下标1。起始分数 `[0,0,0]`，概率各1/3，真实项损失 `−ln(1/3)=ln3≈1.098612`。

只改变B分数，其余两项固定0：

| B分数 | 真实B概率 | 损失（近似） |
|---:|---:|---:|
| −0.01 | 0.331115 | 1.105290 |
| 0 | 0.333333 | 1.098612 |
| +0.01 | 0.335559 | 1.091957 |

往正方向改0.01，损失降低约0.006656；往负方向改，损失反而升高。用两侧结果估计“每改一单位，损失改多少”：

```text
(1.091957−1.105290)/(0.01−(-0.01))
≈ −0.013333/0.02 ≈ −0.6667
```

这个负数告诉我们：在这个位置增加B分数能降低损失。换测A，得到约+0.3333：增加错误候选A的分数，会抢走真实B的概率，从而使损失升高。

这种方法叫有限差分。`ε`读“艾普西隆”，是很小的扰动量；`θ`读“西塔”，代表正在测的参数；`L`是损失。一般写作：

```text
局部变化率 ≈ [L(θ+ε)−L(θ−ε)]/(2ε)
```

每次只动一个数，其余都固定。ε太大测的是较大范围的平均趋势，太小又可能被浮点舍入淹没；在双精度小例中可试0.01、0.001、0.0001，看估计是否稳定。

## 2. 从变化率到导数、梯度

这节给上面的实验命名，带走梯度是每个可调数各自的变化率集合。

当扰动越来越小时，若变化率趋向确定值，就叫导数。多个参数时，每次固定其他参数所得的导数叫偏导。`∂L/∂z_B`读“L对z下标B的偏导”，含义是B分数局部变化一单位时损失的变化率。不要把分数值0和梯度−2/3混为一谈：前者是当前位置，后者是当地坡度。

把三个偏导排成向量，得到对分数的梯度。符号 `∇`读“纳布拉”，表示梯度；本例 `∇z L=[1/3,−2/3,1/3]`。下节解释为什么有这个精确值，有限差分已经给了独立的数值动机。

## 3. 为什么会出现“概率减去标签”

这节从损失的指数形式推导梯度，不要求你凭记忆接受结果。

看不懂求导细节可先跳到第4节，记住结论即可；但请至少核对第1节的有限差分。

真实项为B时，softmax概率为 `e^(z_B)/(e^(z_A)+e^(z_B)+e^(z_C))`。把它代入负对数损失，用对数把除法变成相减：

```text
S = e^(z_A)+e^(z_B)+e^(z_C)
L = −ln(e^(z_B)/S) = −z_B+ln(S)
```

`S`读“艾斯”，是三个指数的和。求导只需三个局部规则：变量自身的变化率是1，`e^u`对u的变化率是`e^u`，`ln S`对S的变化率是`1/S`。例如指数在0附近，从 `e⁰=1`到`e^0.001≈1.0010005`，变化率约1；对数在S=3附近，`(ln3.003−ln3)/0.003≈0.333167`，接近1/3。嵌套计算把相邻变化率相乘，[第06章](06-backprop.md)会展开这个链式法则。

- 调A分数：第一项−z_B不变；S的变化率为`e^(z_A)`；所以L的变化率为 `(1/S)×e^(z_A)=p_A`。
- 调B分数：第一项变化率−1；第二项贡献`p_B`；合计`p_B−1`。
- 调C分数：与A一样，得到`p_C`。

把标签写成独热向量 `y=[0,1,0]`，三个式子可合并为 `∂L/∂zⱼ=pⱼ−yⱼ`，读“每一项的分数梯度等于该项概率减去该项独热标签”。p和y都覆盖整个词表，y不是ID数字1本身。起点p各为1/3，便得到 `[1/3,−2/3,1/3]`。

## 4. 完成一步，再多走一步

这节真正修改参数并复算，带走学习率控制步长、梯度每步重算。

`η`读“伊塔”，表示学习率，是人设置的正数。`θ_new=θ_old−η×梯度`读“新参数等于旧参数减去学习率乘梯度”。本例η=0.3：

```text
新A分数 = 0−0.3×(1/3)  = −0.1
新B分数 = 0−0.3×(-2/3) =  0.2
新C分数 = 0−0.3×(1/3)  = −0.1
指数 ≈ [0.904837,1.221403,0.904837]
指数和 ≈ 3.031078
新概率 ≈ [0.298520,0.402960,0.298520]
新损失 ≈ −ln0.402960 ≈ 0.908918
```

损失由1.098612降到0.908918。第二步不能继续用旧梯度：新梯度约 `[0.298520,−0.597040,0.298520]`；再次乘0.3更新，分数约 `[-0.189556,0.379112,-0.189556]`，B概率约0.4689，损失约0.7573。以同一目标继续重复，B会越来越有优势；但训练语料还有别的前文和真实下一项，不能只对这一条无限调。

## 5. 为什么不靠遍历尝试所有参数

这节说明数值梯度适合检查、解析反向适合训练，并指出局部方法的失败边界。

若有100万个参数，两侧差分需要约200万次损失计算才能测完一轮，代价很大。解析反向传播利用计算结构一次性取得很多参数的梯度；有限差分留下来核对小模型的导数是否写对。

学习率太大并不安全。只看一个局部函数 `L=(θ−1)²`：θ=0时损失1、梯度−2；η=2使新θ=4，损失变9。η=0.1则新θ=0.2，损失0.64。平方例只用来说明步长，不替换本章语言模型的CE目标。

在课程根目录运行：

```bash
python3 labs/foundations.py --json
```

核对有限差分和解析梯度，以及第一步CE。这里列出的值是预期数学值；别拿这一个局部更新的下降当成完整训练或保留集改善。

## 小测

1. 起点不变，学习率改为0.6，新分数是多少？为什么B向上、A/C向下？

<details><summary>展开答案</summary><p>[-0.2,0.4,-0.2]。减去梯度：B梯度负，因此增加；A/C梯度正，因此降低。方向来自损失对分数的变化，不来自ID大小。</p></details>

2. 某候选原分数0.7，损失对它的偏导是−0.4，学习率0.05，新分数多少？梯度为负是否意味着分数必须为负？

<details><summary>展开答案</summary><p>0.7−0.05×(-0.4)=0.72。分数是位置，梯度是变化趋势，两者正负没有这样的对应关系。</p></details>

3. 数值梯度与解析梯度不一致，能直接调大学习率解决吗？先查什么？

<details><summary>展开答案</summary><p>不能。先固定相同输入/参数/目标与损失聚合口径，每次只扰动一个参数，检查扰动后恢复原值，换几个合理ε；再查解析推导和轴。学习率不参与导数的定义。</p></details>
