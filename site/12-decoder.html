本章把注意力放进一条完整计算路径，解释每个部件为什么存在，并把最后的向量变成词表概率。前置是位置与多头以及隐藏层与反向传播。这里的 decoder 是只读合法前缀的文本预测网络，不包含翻译模型里的交叉注意力。

1. 先认清完整路线

这节先给全图，后面的计算都能在图中找到位置。

多头注意力负责跨位置读取信息，但“读回来一个向量”还不等于完成预测：我们还要保留原输入、控制计算尺度、做逐位置的非线性变换，再映射到词表。

本课代码使用 Pre-LN，即“先层归一化，再进子层”。以一行向量为单位写：u=x+Attention(LN(x))，再算 y=u+FFN(LN(u))。x 是块输入，u 是第一次相加的结果，y 是块输出；括号说明先执行哪个函数。注意力需要同时看整段合法前缀，FFN与LN则逐行处理。

这里不推导整块反向传播。难点看不懂可先记住：每块两次残差相加，块宽度始终不变；输出头才把特征维变成词表维。

2. LN为什么要有 epsilon

这节手算一行的层归一化，分清特征统计与跨样本统计。

假设某行是 [1,3]。先取均值 (1+3)/2=2；减均值得到 [-1,1]；平方后平均是 (1+1)/2=1，这就是本例采用的方差。取平方根得到尺度1，再除以这个尺度，就得到 [-1,1]。这使子层接收到的各行尺度更可控，但不保证每次训练一定稳定。

实际还要在方差里加一个小正数。用 ε=0.00001，ε 读“艾普西隆”，代表防止除零的小量，结果约为 [-0.999995,0.999995]。一般规则是：

LN(x)_j = γ_j × (x_j - μ) / sqrt(σ² + ε) + β_j

j 是特征下标；μ 读“缪”，是一行各特征的均值；σ² 读“西格玛平方”，是各特征偏差平方的平均；sqrt 表示平方根；γ 读“伽马”，是可训练缩放；β 读“贝塔”，是可训练偏移。若 γ=[2,0.5]、β=[0,1]，上面的结果进一步变成约 [-1.99999,1.4999975]。

为什么不能删掉 ε？看 [0.001,0.001]：均值也是0.001，两个偏差都为0，方差为0；没有 ε 就会算 0/0。有 ε 则归一化结果为 [0,0]。再看 [0,0.00002]，均值0.00001，方差0.0000000001；加 ε 后分母约0.00316229，结果约 [-0.00316226,0.00316226]，不是强行变成 [-1,1]。小方差时 ε 实际影响数值，不能把它说成永远可以忽略。

LN沿每个 token 的特征轴算，不混合不同位置。因此改未来行不会通过这个LN影响过去行；若误写成整段时间轴一起求均值，就可能破坏因果性。

3. 残差与FFN各做什么

这节算完一个局部数值路径，知道残差和非线性不是同一件事。

先把注意力分支的输出视作已经算好的 [0.5,-0.5]，块输入为 [1,3]，第一次残差得到 u=[1.5,2.5]。这不是“选择原输入或新结果”，而是逐项相加。分支可以学修正量，原向量保留一条直接到后面的路径；它不等于保存原始字符串，也不保证信息不丢失。

为方便手算，下面独立局部例用ReLU，实际实验用GELU。暂把 ε 当作极小量近似，LN(u)≈[-1,1]。设第一层映射：

[-1,1] × [[1,-1],[1,1]] + [1,0] = [1,2]
ReLU([1,2]) = [1,2]
[1,2] × [[1,0],[0,0.5]] + [0,0] = [1,1]
第二次残差：[1.5,2.5]+[1,1]=[2.5,3.5]

ReLU读“瑞鲁”，逐项取“该数与0中的较大者”，例如 [-2,0,3] 变 [0,0,3]。若中间不插非线性，多次线性映射仍可合成一次线性映射，表达方式受限。GELU是另一个平滑的非线性函数，不等于ReLU；手算例没有冒充代码trace。

FFN读“前馈网络”，在这里就是每行独立的两层映射与非线性。所有位置共享同一组参数，却不彼此读取。实际每行 32→128→32，中间128维提供更宽的变换空间，回到32维才能与残差相加。注意力混合位置，FFN混合该位置的特征，两者职责不同。

4. 最后怎样变成概率

这节把词表投影和softmax接上，区分特征数与候选token数。

设最后归一化后的一行向量是 [1,-1]，演示词表只有A、B、C。取数学行向量右乘的输出矩阵：

W_vocab = [[1,0,-1],
           [0,0, 0]]
logits = [1,-1] × W_vocab = [1,0,-1]

logits 是未归一化分数，不是概率。指数约为 [2.7183,1,0.3679]，总和约4.0862，因此概率约 [0.6652,0.2447,0.0900]。三个分数对应三个候选 token，不是输入里的三个位置。

阶段 完整模型形状 含义
token与位置相加 [B,T,32] 每个位置的输入表示
2个decoder块 [B,T,32] 读过合法前缀的表示
最终LN [B,T,32] 进入输出头前的表示
词表头 [B,T,V] V是训练集拟合出的词表大小
softmax [B,T,V] 各位置预测下一token的分布

实际词表头无偏置，且不与输入嵌入共享参数。PyTorch的 Linear 把权重存成 [输出维,输入维]，所以存储矩阵是上面数学矩阵的转置。若直接照着数学数组填框架权重而不转置，就会把接口弄反。训练时交叉熵函数可直接接收logits，内部处理稳定的归一化计算，无需先手动softmax再喂进去。

5. 在代码里沿路线走一次

这节给可执行入口，再用检查问题约束阅读，而不是凭模型名称猜内部结构。

python3 -m llm_course.experiments
python3 -m unittest discover -s tests -v

实验检查因果边界和缓存一致性；测试通过不表示每个结构选择都最好。打开 llm_course/model.py，逐项找：嵌入、位置表、两个Pre-LN块、GELU、最终LN、词表头。记录模型配置是否为宽32、4头、2层、上下文64、dropout0；命令行改过配置时，以自己报告中的配置为准。

故障定位：若残差两边分别是32维与128维，相加在形状上就错了；若全网logits已含未来信息，最终softmax不会替你修复；若初始化模型能输出完整句子，也不能由一句话断言它训练过。

6. 换数小测

这节检查能否把计算和接口说清。

  1. [2,2] 做LN，γ=[1,1]、β=[0,0]、ε为正，结果多少？
  2. 输入 [2,-1]，分支结果 [-0.5,0.25]，残差相加结果多少？若分支是3维能直接相加吗？
  3. 词表大小7、特征宽32，一条长5的序列得到什么形状的logits？最后一行有几个候选分数？
展开完整答案

  1. 均值2，偏差均为0，方差0，除以sqrt(ε)后仍为0，因此得到[0,0]。不能删ε后说结果仍然有定义。

  2. 逐项相加得到[1.5,-0.75]。3维分支不能直接与2维输入相加，需先设计投影使宽度一致；本课FFN第二层就是回到残差宽度。

  3. 包含批轴时为[1,5,7]，最后一行7个候选分数。32是内部表示宽度，不是输出候选数；最后一行用于预测当前前缀之后的下一token。
