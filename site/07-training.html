自动求导负责沿计算图算梯度；训练程序还必须正确管理清梯度、更新、数据分工和保存状态。代码能运行不等于任务设对，训练损失下降也不等于新数据改善。 本章先复现小网络，再阅读可扩展的训练循环。

前置：第05章的梯度下降、第06章的链式法则。不要求你已熟悉Python或PyTorch；下面只介绍本次要读的接口，完整模型留在后续章节。

1. 张量是什么，和数组差在哪里

这节给软件读者一座最短的接口桥，带走“形状、类型、求导状态”三个检查点。

PyTorch是一个数值计算与自动求导库。tensor读“张量”，可以先理解为带形状和类型的多维数组。torch.tensor([[1.,2.],[3.,4.]])是2行2列的浮点张量；.shape给出[2,2]。后缀点号是对象方法/属性访问，和Java的调用风格类似；Python缩进表示代码块，没有大括号。

本章接口 做什么 容易写错的地方
torch.tensor(...) 建立张量 token ID和类别标签用整数long，参数/分数用浮点
requires_grad=True 为该浮点变量记录求导关系 整数ID本身不求梯度
@ 矩阵乘法 *是逐元素乘法
.backward() 从标量损失往回累加梯度 默认会累加，下一轮要清理
.grad 读取梯度 不等于参数的新值
.item() 将单个数转成Python数值 调用后脱离原计算图

参数表会收到梯度，但“选择第几行”的ID不需要梯度；自动求导只对本次查到的浮点运算反传。

2. 先用三个分数核对自动求导

这节复现已手算的更新，带走“框架计算也要对着已知答案检查”。

先按课程安装说明安装训练依赖，再在课程根目录运行下面片段。可以存为check_update.py后执行python3 check_update.py，完成后自行删除该临时文件。

import torch
import torch.nn.functional as F

z = torch.tensor([[0., 0., 0.]], requires_grad=True)
target = torch.tensor([1], dtype=torch.long)
loss = F.cross_entropy(z, target)
loss.backward()
print('loss:', loss.item(), 'gradient:', z.grad)
with torch.no_grad():
    z -= 0.3 * z.grad
print('new scores:', z)
print('new loss:', F.cross_entropy(z, target).item())

预期旧损失ln3≈1.098612，梯度一行 [1/3,−2/3,1/3]；新分数[-0.1,0.2,-0.1]，新损失约0.908918。这里z就是待更新的一行参数，没有深层网络，形状[1,3]表示一条样本、三个候选。

F.cross_entropy直接接原始分数，内部完成数值稳定的log-softmax与真实项罚分。不要先softmax再传进去。 若真实分数[0,1,0]，真实B概率约0.5761；先算成概率再把它当分数，内部还会再转一次分布，任务函数已变化。

torch.no_grad()表示这个代码块不记录求导关系。参数更新属于训练状态修改，通常不需要为“更新动作本身”再建立新的求导图；它不会抹掉先前算好的.grad。

3. 从一个单元到小MLP

这节运行带隐藏层的模型，带走“前向、解析梯度、数值梯度、自动求导要说同一件事”。

python3 -m llm_course.mlp

实验包含一个固定的“两输入→两隐藏单元ReLU→三候选”局部例，核对解析、有限差分与自动求导的梯度，并执行一次更新；随后用两字符窗口做分类训练：A编码0、B编码1，标签是窗口内B的个数，类别为0/1/2。这里A/B的二值编码是特意设计的分类特征，不是语言模型的通用token距离。它与第06章的一隐藏单元例参数不同，比较时先看输入、权重与形状，不能拿两个损失值直接相减。

固定例的输入是[1,2]、目标下标1。第一层按PyTorch的每行一个隐藏单元存储：

W1=[[0.2,0.1],[0.1,0.3]]，b1=[0.1,0.2]
隐藏第1项=0.2×1+0.1×2+0.1=0.5
隐藏第2项=0.1×1+0.3×2+0.2=0.9
两项都是正数，ReLU保持[0.5,0.9]
W2=[[0.1,0.2],[0.3,−0.1],[−0.2,0.4]]，b2=[0,0.1,−0.1]
输出第1项=0.1×0.5+0.2×0.9=0.23
输出第2项=0.3×0.5−0.1×0.9+0.1=0.16
输出第3项=−0.2×0.5+0.4×0.9−0.1=0.16

本次CPU实际运行，softmax约为[0.349066,0.325467,0.325467]，CE约1.122494；SGD学习率0.1更新一次，目标概率升到约0.397314，CE约0.923028。解析与有限差分的梯度最大绝对差约1.91×10⁻¹¹，与autograd约1.11×10⁻¹⁶；这表明此处计算互相吻合，不能扩成“任何网络都已验证”。

两个隐藏单元如何接收梯度？由本例目标1，三个输出分数的梯度为dz=[0.349066,−0.674533,0.325467]。第一隐藏单元收到0.349066×0.1−0.674533×0.3+0.325467×(−0.2)≈−0.232547；第二个收到0.349066×0.2+(−0.674533)×(−0.1)+0.325467×0.4≈0.267453。它们分别沿W2的对应列累加三条输出路径。本次两个ReLU输入均为正，再乘局部导数1，梯度继续回到第一层；这就是第06章“分叉相加”在多输出网络里的应用。

后半段分类用Adam训练300步，训练CE从约1.08344降到0.005347。训练文档和评价文档虽分开，AA/AB/BA/BB四种可能窗口却都出现在两边；它只演示优化闭环，不是独立泛化证据，更不是下一token语言模型结果。

运行前先做三个预测：更新前后是否使用同一真实目标；梯度是否和参数形状一致；如果把一步更新的学习率改为0，参数和损失会怎样。运行后在输出中找到对应证据。这个小实验优先于完整decoder，是为了把“手算的乘加”与“框架保存的图”接起来，不要求它展示真正语言能力。

在数学行向量约定里，线性层写h=xW+b；nn.Linear(2,3)保存的.weight形状却是[3,2]，.bias为[3]。用数学W复现时，应把它的转置复制进.weight。例如输入[2,1]，权重存储的第一行为[0.5,-1]，第一输出是2×0.5+1×(-1)+b₀。这与第02章相同，不是库换了一套数学。

4. 循环的顺序为什么如此固定

这节把训练写成状态变化，带走每次更新使用哪一次前向的梯度。

import torch
import torch.nn.functional as F
from llm_course.mlp import TinyMLP

model = TinyMLP()  # 使用本章固定参数，内部为float64
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
inputs = torch.tensor([[1., 2.]], dtype=torch.float64)
targets = torch.tensor([1], dtype=torch.long)
optimizer.zero_grad(set_to_none=True)
logits = model(inputs)
loss = F.cross_entropy(logits, targets)
loss.backward()
optimizer.step()

这是适用于“每条输入一个目标”的MLP骨架，不是完整decoder接口原样复制。optimizer是更新器，持有模型参数；最简单的SGD就是第05章的减法。完整实验若用AdamW，步长还结合历史梯度统计和权重衰减，不能用单步SGD数字要求它逐项相等。

遗漏清理会怎样？本次偏导0.2，下一次偏导0.3；若不清理，第二次.grad得到0.5，而非0.3。累积有时是有意的大批量模拟，但要明确归一化；无意保留就是错误。

验证时同时使用model.eval()与torch.no_grad()：前者切换dropout等模块行为，后者停止构建求导图，职责不同。当前课程完整模型dropout为0，但不能把两接口说成同义词。

5. 看报告，不只看一条下降曲线

这节说明该如何决定保存哪一版，带走测试数据不参与参数更新或版本选择。

假设训练到三次检查：

检查步 训练CE 验证CE
50 1.2 1.3
100 0.8 1.0
150 0.5 1.1

这是说明性数字。按验证CE选择第100步，而非训练CE最低的150步；最后再对选中权重计算测试CE。验证不更新参数，却通过版本选择影响最终方案，不能称它完全没参与开发。

保存检查点时要带参数、结构配置、词表映射和预处理规则。相同权重配错ID映射，数值可运行却会把字符含义打乱。续训还需更新器状态与步数；“可恢复推理”不自动等于“可无缝恢复训练”。

最小诊断顺序：先核目标是否真为下一项；再看少量数据能否降低训练损失；再查梯度非空/数值有限、参数是否变化；最后才讨论加层。刻意在小批数据上拟合是排查计算链的探针，不能作为泛化证据。后续第14章会使用报告比较计数模型与decoder，本章不要求提前运行。

小测

  1. nn.Linear(4,3)保存的权重与偏置形状是什么？输入5条样本时输出形状是什么？
展开答案

权重[3,4]、偏置[3]；输入[5,4]，输出[5,3]。5是样本轴，3是候选/输出轴，不能交换含义。

  1. 训练CE从0.9降到0.3，验证CE从1.0升到1.4，是否立刻增加模型层数？
展开答案

不应仅据此加层。先核对数据切分、分布差异、验证口径和过拟合；训练拟合加强但保留表现恶化，加容量未必解决。选择更早的验证最优版本并保留测试验收。

  1. 你在验证循环调用了.backward()，但没调用step()。参数是否已经变化？下一步有什么风险？
展开答案

通常backward只累加梯度，尚未修改参数；但验证梯度可能混入下一次更新。验证应不建图、不反传，训练更新前清理梯度。
