更多前文只有进入计算才有用。固定窗口明确保留位置却会截断远处信息；简单平均能汇总多个token，却会丢失顺序和针对当前问题的选择能力。 注意力将提供按当前输入计算权重的办法，但它本身不会自动知道先后顺序。

前置：嵌入与输出层、隐藏层、token序列。本章的平均和拼接都用手设向量，目标是找到具体信息损失，而非宣称某个向量已学出语义。

1. 只看最后一个token，存在无法消除的歧义

这节用相同末项、不同前文说明输入不足，带走有些错误不能靠再训练同一接口解决。

考虑两条教学前文：请求 成功 后、请求 失败 后。希望第一条续写“返回”，第二条续写“重试”。若输入只保留“后”，两个前文进入模型后完全相同，同一参数必然输出同一分布。增加训练次数可以改变这个共同分布，却无法让同一个输入同时按两种前文分别回答。

假设两类前文在训练中各出现一次，正确后项分别为“返回/重试”。只看“后”的模型折中成各0.5，两条损失均为 −ln0.5≈0.693147；若偏向返回到0.9，第一条损失约0.105361，第二条约2.302585，平均约1.203973，反而更差。输入边界造成的冲突不会因更自信而消失。

2. 固定窗口拼接：有顺序，但有固定成本

这节把两个token的表示拼起来，带走位置是通过排列进入计算的。

设“成功”向量为[1,0]，“失败”为[0,1]，“后”为[1,1]。取最近两个token，按“较早→较晚”拼接：

成功 后 → [1,0,1,1]
失败 后 → [0,1,1,1]

现在输入不同，模型至少有区分条件。给“返回”的打分权重[1,−1,0,0]，偏置0：第一条分数 1×1+0×(-1)+1×0+1×0=1；第二条 0×1+1×(-1)+1×0+1×0=−1。只需一组线性权重就能区分这两个局部例，未必一开始就需要注意力。

若窗口长度K=2、每token维度d=2，拼接维度K×d=4；若接3个隐藏单元，第一层需要 4×3+3=15个参数。K改为4，输入变8维，同一隐藏宽度需要 8×3+3=27个。K读“凯”，表示窗口里保留多少token；d读“迪”，表示每个token的表示宽度。它们的乘积是拼接长度，不是词表大小。

失败例是成功/失败与“后”之间插入许多“记录/日志”片段，超过K后两条输入重新一样。增大K能覆盖更远信息，但输入和参数规模也增长，而且仍存在新的边界。窗口不是坏设计：短期局部规律可能用它便宜解决；只是边界应明确。

3. 用平均节约长度，究竟丢了什么

这节逐项计算平均，带走“相同词袋、不同顺序会碰撞”。

为了让输入维度不随长度变大，可以把所有token向量相加再除以数量。取手设的二维向量：

服务=[1,0]，超时=[0,1]，重试=[1,1]
逐项相加：[1+0+1,0+1+1]=[2,2]
除以3：平均向量=[2/3,2/3]

一般记输入向量为x₁…xₙ，n读“恩”，表示token数；m读“艾姆”，表示平均向量；Σ读“求和”。公式 m=(x₁+…+xₙ)/n，例如本例n=3，m=[2/3,2/3]。

把顺序换成重试 超时 服务，相加仍是[2,2]，平均也不变。由于加法交换次序不改结果，平均之前若没有携带位置的表示，下游再复杂也无法恢复已被合并掉的顺序。这不是只看二维向量才有的问题。

平均还会稀释稀有线索。一个“超时”向量[0,1]和三个“服务”向量[1,0]，平均为[3/4,1/4]；若换成九个“服务”，平均变为[9/10,1/10]。超时仍出现了一次，但它在平均里的占比从1/4降到1/10。是否该稀释，取决于任务，不应默认所有token同等重要。

4. 为什么想要“针对当前需要”重新分权重

这节从均匀平均过渡到可变加权和，带走我们给下一章提出的计算需求。

还是“服务/超时/重试”三个向量，平均隐含每项权重都是1/3。若本次更想突出“超时”，手动给权重 [0.1,0.8,0.1]：

第一维：0.1×1+0.8×0+0.1×1=0.2
第二维：0.1×0+0.8×1+0.1×1=0.9
输出：[0.2,0.9]

权重非负、和为1，得到加权混合。它不是“选择超时后原样拷贝”，因为服务和重试仍贡献了内容。本章权重是人为指定，尚未解释来源；下一章会从每个位置的查询、键和值计算它们。不同位置可以有不同权重，才不必用同一个摘要满足所有位置。

注意力需要解决三件事：从当前表示计算可比较的分数；把分数转成权重；用权重混合内容。生成模型还必须禁止当前预测读取未来token。这几步都不等于位置编码。 若只根据内容分配权重，没有注入顺序信息，也没有任何区分位置的机制，就不能声称它天然知道哪个词先来。

因果遮罩会限制可见范围，但不要把“看不见未来”与“完整知道相对距离”混为一件事。位置表示将由第11章专门展开；第10章先算内容匹配和遮罩。

5. 纸上碰撞测试

这节给一种不训练模型也能验证表示缺陷的方法，带走“先检查输入能否区分任务”。

画三列：原始前文、经过表示后的输入、期望输出。分别填入顺序相反但token相同的两条前文。若平均后输入完全一样，而任务明确要求不同输出，就找到了表示碰撞；模型再深也无法从这份相同表示识别是哪条原文。

可以运行下面的小片段验证平均碰撞：

vectors = {'服务': [1, 0], '超时': [0, 1], '重试': [1, 1]}
def mean(words):
    return [sum(vectors[w][j] for w in words) / len(words)
            for j in range(2)]
a = ['服务', '超时', '重试']
b = list(reversed(a))
print(mean(a), mean(b), mean(a) == mean(b))

预期两个向量均约[0.6667,0.6667]，比较为True。这个试验只能证明当前表示丢了顺序，不能证明所有平均模型都没有价值：若任务只是统计主题，顺序不敏感也许正合适；若平均之前已加入上下文与位置信息，前提也发生了变化。

小测

  1. 两个token向量[2,0]与[0,4]，平均是多少？权重改为[0.75,0.25]又是多少？
展开答案

均匀平均为[1,2]。加权后第一维0.75×2+0.25×0=1.5，第二维0.75×0+0.25×4=1，得到[1.5,1]。两个权重和为1，但不是均匀分配。

  1. K=3的固定窗口预测时，“成功”与“失败”都在距末端10个token的位置，只改变那里，模型一定能响应吗？
展开答案

不能。如果它只读取最后3个token，那个差异不在输入里；两个输入完全相同。改进需要改变可见范围或加入能携带更早信息的表示，而不是只增加训练步数。

  1. 有人说“注意力权重最高的词就是导致回答的原因，而且注意力天然知道顺序”。应怎样纠正？
展开答案

权重描述一次混合计算，内容还受值向量、其他头、残差和后续层影响，不能直接当因果解释；顺序也需要位置机制或其他顺序相关结构。先查看完整计算与输入限制，再设计干预实验，不能从一个大权重推出这两种结论。
