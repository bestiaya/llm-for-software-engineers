# 06｜隐藏层、链式法则与反向传播

**前向传播保存每一步算出的中间值；反向传播把损失的变化率沿原计算路径传回参数。多条路径汇入同一个参数时，贡献要相加。** 隐藏层不是藏起来的知识库，而是输入到输出之间的一层计算。

前置：[第04章的嵌入与输出层](04-parameters.md)、[第05章的局部梯度](05-gradients.md)。本章只手推一个小隐藏单元，不手推整个Transformer。

## 1. 为什么在两张矩阵之间插入非线性

这节说明隐藏层增加了什么，带走“只连续相乘，不自动增加表达形式”。

如果先乘2、再乘3，输入x最后得到6x；两层线性计算等于一层。矩阵也一样：先乘一张表再乘另一张表，仍可合成一个线性映射。加偏置后仍可合成一个“乘加”映射，因此仅仅堆很多线性层不够。

插入一个分段函数就不同。ReLU读“瑞路”，中文常称修正线性单元，规则是“负数改成0，正数原样保留”。例子：

```text
输入x       -1    0    1    2
先算2x−1    -3   -1    1    3
过ReLU       0    0    1    3
```

不存在一条直线能同时通过这四个输出点：x=-1到0时输出不变，x=1到2时输出增加2。非线性让隐藏层能组合出不同区域的不同响应，不保证它一定学到有用规律。

固定窗口文本模型可以把前两个token的嵌入按位置拼接，再经过隐藏层，最后输出下一token的分数。MLP读“多层感知机”，在这里指这种由线性层和非线性组成的网络；它的输入窗口大小在设计时固定，不是任意长记忆。

## 2. 把一个隐藏单元前向算到底

这节建立能手推的计算图，带走每一个中间量的来历。

为了让反向链短到可核，本节用一个已经给定的输入特征x=2，它可理解为查表后取出的一项。它不是把token ID当连续大小。可训练数为输入权重w=0.5、隐藏偏置b=0、输出权重u=1。三个候选中只让B分数接到这个单元，A/C分数固定0。

```text
a = w×x+b = 0.5×2+0 = 1
h = ReLU(a) = 1
z_B = u×h = 1×1 = 1
z = [0,1,0]
p_B = e/(1+e+1) ≈ 0.576117
L = −ln(p_B) ≈ 0.551445
```

`a`读“诶”，是非线性之前的数；`h`读“艾尺”，是隐藏输出；`u`读“优”，是隐藏输出到B的连接权重。w、b、u是参数，a、h、z、p是这次前向的中间结果。`ReLU(a)=max(0,a)`，max读“取较大者”，例如a=-1时输出0，a=2时输出2。

## 3. 链式法则是变化量的接力

这节把每一段变化率相乘，带走反向传播没有凭空改写数学。

先不看符号：w增加0.001，会使a约增加 `2×0.001=0.002`；a在正数区，所以h也增加0.002；u=1，zB也增加0.002；末端损失对zB的变化率约−0.423883，因此损失约变化 `−0.423883×0.002=−0.000847766`。除以w的变化0.001，得到约−0.847766。

符号 `∂L/∂w`读“损失对w的偏导”。链式法则写成：

```text
∂L/∂w = (∂L/∂zB)×(∂zB/∂h)×(∂h/∂a)×(∂a/∂w)
       ≈ (-0.423883)×1×1×2 = -0.847766
```

各段含义与数字如下：

| 段 | 为什么是这个变化率 | 数字 |
|---|---|---:|
| 损失←zB | 第05章推导的pB−1 | −0.423883 |
| zB←h | zB=u×h，u固定 | u=1 |
| h←a | a>0时ReLU原样通过 | 1 |
| a←w | a=w×x+b，x固定 | x=2 |

另两项也要算：对u的梯度是 `(pB−1)×h≈−0.423883`；对b的梯度是 `(pB−1)×u×1≈−0.423883`，因为a随b增加一单位也增加一单位。偏置并不会因“没乘输入”而没有梯度。

学习率0.1，所有梯度从**同一旧状态**计算，再同时更新：

```text
w_new≈0.584777，b_new≈0.042388，u_new≈1.042388
新a≈0.584777×2+0.042388≈1.211942
新zB≈1.042388×1.211942≈1.263314
新pB≈0.63880，新损失≈0.44816
```

这是一个单样本局部例的预期算术；它没有训练词向量或完整网络，也不能用来宣称语言能力。若先改u再用新u算w梯度，算的是另一套更新规则，无法和这次同时更新对照。

## 4. 分叉、共享与零梯度

这节处理真实网络多于一条路径的情况，带走“复用同一参数时梯度累加”。

假设同一个权重r在两条路径出现，输出 `s=r×2+r×3`。r=1时s=5，r增加0.01，两路分别增加0.02和0.03，合计0.05，所以s对r的变化率是5。不能只保留最后一路的3。文本模型同一token在很多位置出现，共享嵌入行的梯度也要汇总这些位置的贡献，再按所用损失均值缩放。

ReLU的另一侧则会切断局部变化。把w改成−0.5、b仍为0，a=−1、h=0、zB=0；在小幅扰动还不穿过0时，h始终为0，因此w的梯度为0。梯度为0不代表整个任务已经最好，只表示沿当前这条局部路径推不动。a=0恰是折点，普通导数不存在；框架约定一个值（PyTorch取0），数值检查应避开这个点。

实际decoder可以用更平滑的GELU激活；本章选ReLU是为了手算分段变化率，不能把这个教学单元当成后续模型的完整配置。

## 5. 自己核对反向传播

这节给出不依赖自动求导的核查方法，带走数值结果必须同一个函数同一个状态比较。

```python
import math

def loss(w):
    h = max(0.0, w * 2.0)  # 固定b=0、u=1
    return math.log(2.0 + math.exp(h)) - h

eps = 0.0001
numeric = (loss(0.5 + eps) - loss(0.5 - eps)) / (2 * eps)
print(numeric)  # 预期约 -0.847766
```

它只检查w这一项，b、u都固定。也可以运行 `python3 labs/foundations.py` 查看另一函数的链式检查：脚本使用L=(wx+b)²、x=2、w=3、b=1，预期对w的导数是28。它与本章ReLU/交叉熵的−0.847766是不同例子，不能直接对照数值；要复现本章数字，请运行上面这段代码。有限差分不是第二种学习目标，而是确认同一目标的导数是否正确。

故障例：前向把h算成1，反向却读取已更新后的h；或者把一次独立扰动永久留在参数中，下一项核对就不在同一个起点。先保存原始状态，每次恢复后只动一个参数。

## 小测

1. 仍在原始状态，若输入特征x从2改成1，w=0.5、b=0、u=1，a和pB是多少？w梯度还等于原来吗？

<details><summary>展开答案</summary><p>a=h=zB=0.5；pB=e^0.5/(2+e^0.5)≈0.451863。w梯度=(pB−1)×u×1×x≈−0.548137。前向值和局部乘数都变了，不能沿用旧梯度。</p></details>

2. 同一参数r出现在 `s=4r−r` 两路，s对r的导数是多少？

<details><summary>展开答案</summary><p>第一路贡献4，第二路贡献−1，合计3。分叉反向贡献相加；不能把两路的4与−1相乘。</p></details>

3. a=-1时ReLU输出0，w梯度为0，能说损失已最小吗？

<details><summary>展开答案</summary><p>不能。本例三个分数全0，B概率1/3，仍有损失ln3。只是ReLU在当前负半轴的局部导数为0，使该路径传不到w；其他参数、数据或初始化仍可能改变结果。</p></details>
