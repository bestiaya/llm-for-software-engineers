# 数据来源与边界

## 自然语言实验

`real.txt` 是 Lewis Carroll（1832–1898）的英文原作 *Alice's Adventures in Wonderland*（1865）书体，来源为[Project Gutenberg 第11号电子书](https://www.gutenberg.org/ebooks/11)。它是真实文学文本，不是课程生成的语法串，也不是中文服务日志。

- 原始下载文件完整保存在 `sources/alice-original.txt`，未改动字节，包含原电子书的许可与来源声明。
- 实验文件仅作UTF-8解码、CRLF转LF、移除开头目录与电子书元数据，保留章节正文。具体日期、步骤及SHA-256见 `real-provenance.json`。
- 原站标注该作品在美国属于公版。原电子书的使用与分发说明随源文件及 `sources/PROJECT-GUTENBERG-LICENSE.txt` 保留；本课程的MIT许可证不替代第三方数据条款。美国之外使用者需核对所在地区适用条件。
- 训练代码先切分原文，再在训练部分拟合字符词表。相邻文本段并不统计独立，同一书中的重复表达仍会影响泛化解释。固定测试被用于课程验证后，不称为新的盲测。
- 这些实验只能说明本配置在这本英文文本上的预测与生成行为，不证明中文能力、助手能力、事实可靠性或软件运维能力。

## 有限语法实验

有限语法由 `llm_course/data.py` 的 `toy_groups()` 在内存中生成，使用原创的服务状态短语规则；不需要另行下载toy文件，实际内容的SHA-256记录在训练报告中。按完整唯一组分训练/验证/测试，避免同一组跨集合。生成规则说明见[toy-provenance.md](toy-provenance.md)。它用于验证训练循环、基线与数据流，不代表自然语言分布或实际服务日志。
